## P0-1：Redis 从零到项目实战（1-2 周）

### 学习路径

#### 阶段一：入门基础（Day 1-3）

**目标：** 理解 Redis 是什么，掌握 5 大数据类型的基本操作。

**具体步骤：**

1. **安装 Redis**
   - Windows：下载 [Memurai](https://www.memurai.com/)（Redis 的 Windows 原生版本）或使用 WSL2 安装
   - Linux / WSL：`sudo apt install redis-server && sudo systemctl start redis-server`
   - 验证安装：`redis-cli ping` → 返回 `PONG`

2. **跟着教程学习 5 大数据类型**
   - 打开 [Redis 中文教程](https://redis.com.cn/tutorial.html)，按章节顺序操作
   - 每种类型在 `redis-cli` 中亲手敲一遍命令
   - 重点掌握：
     - `String`：`SET` / `GET` / `INCR` / `SETEX`（缓存 + 计数器）
     - `Hash`：`HSET` / `HGET` / `HMGET`（对象存储）
     - `List`：`LPUSH` / `RPUSH` / `LRANGE`（消息队列）
     - `Set`：`SADD` / `SMEMBERS` / `SINTER`（去重 + 交集）
     - `ZSet`：`ZADD` / `ZRANGE` / `ZREVRANK`（排行榜）

3. **观看入门视频**（可选，推荐 2x 速）
   - [知乎超强入门教程](https://zhuanlan.zhihu.com/p/411888708)（图文版，30 分钟读完）

#### 阶段二：进阶实战（Day 4-7）

**目标：** 掌握 Redis 在后端项目中的典型应用场景。

**具体步骤：**

1. **学习 Redis 在 Python 中的使用**
   - 安装：`pip install redis`
   - 写一个 50 行的 FastAPI 小 demo：用 Redis 缓存 API 响应
   - 关键代码模式：
     ```python
     import redis
     r = redis.Redis(host='localhost', port=6379, decode_responses=True)
     
     # 缓存模式：先查缓存，没有再查数据库
     def get_user(user_id):
         cached = r.get(f"user:{user_id}")
         if cached:
             return json.loads(cached)
         user = db.query("SELECT * FROM users WHERE id = %s", user_id)
         r.setex(f"user:{user_id}", 300, json.dumps(user))  # 5分钟过期
         return user
     ```

2. **学习三大缓存问题**
   - **缓存穿透**：查询不存在的数据 → 布隆过滤器 / 缓存空值
   - **缓存击穿**：热点 key 过期 → 互斥锁 / 永不过期
   - **缓存雪崩**：大量 key 同时过期 → 随机过期时间
   - 推荐阅读：[Redis 从入门到实战：全面指南（CSDN）](https://blog.csdn.net/weixin_45981509/article/details/148529249)

3. **在 HIS 项目中集成 Redis**
   - 场景 1：缓存 AI 服务的预测结果（`/api/v2/predictions` 结果缓存 5 分钟）
   - 场景 2：管理员登录 Token 存储（替代内存存储）
   - 场景 3：药品库存查询缓存
   - 在简历中写入："引入 Redis 缓存层，AI 预测接口响应时间降低 XX%"

#### 阶段三：面试准备（Day 8-10）

**目标：** 能回答面试中 80% 的 Redis 问题。

**必背知识点：**

| 问题 | 核心答案 |
|------|---------|
| Redis 为什么快？ | 内存操作 + 单线程避免上下文切换 + IO 多路复用 |
| 持久化方式？ | RDB（快照）+ AOF（追加日志），各有优缺点 |
| 过期删除策略？ | 惰性删除 + 定期删除 |
| 内存淘汰策略？ | LRU / LFU / TTL / 随机等 8 种 |
| 和 Memcached 区别？ | Redis 支持更多数据类型、持久化、主从复制 |

## P0-2：LeetCode Hot 100 刷题计划

### 刷题策略

**核心原则：按类型刷，不要按序号刷。**

推荐刷题顺序（由易到难）：

| 周次 | 专题 | 题数 | 代表题目 |
|------|------|:---:|------|
| 第 1 周 | 哈希表 + 双指针 | 15 | 两数之和、三数之和、合并两个有序数组 |
| 第 2 周 | 滑动窗口 + 子串 | 10 | 无重复字符的最长子串、找到字符串中所有字母异位词 |
| 第 3 周 | 链表 + 二叉树 | 15 | 反转链表、合并 K 个升序链表、二叉树中序遍历 |
| 第 4 周 | 回溯 + BFS/DFS | 12 | 全排列、子集、岛屿数量 |
| 第 5 周 | 动态规划 | 15 | 爬楼梯、最长回文子串、编辑距离 |
| 第 6 周 | 贪心 + 排序 + 其他 | 13 | 跳跃游戏、合并区间、最小栈 |

### 每日流程（建议 1-2 小时）

1. **读题 + 独立思考（15-20 分钟）**：不看题解，尝试自己想
2. **写代码（20-30 分钟）**：在 LeetCode 在线编辑器中写
3. **看题解（10-15 分钟）**：如果没做出来，看官方题解或点赞最高的讨论
4. **重写（10 分钟）**：理解后关闭题解，自己重新写一遍
5. **记录**：在笔记中记录题目编号、类型、核心思路（一句话）

1. **注册 LeetCode 中国站账号**：[leetcode.cn](https://leetcode.cn/)

4. **三刷策略**：
   - 一刷：理解思路，能写出代码即可
   - 二刷：手写代码，不看任何参考，限时 20 分钟/题
   - 三刷：限时 10 分钟/题，追求最优解

### 方案 A：Go Gin 项目（推荐新手快速出成果）

2. **学习 Go 基础语法**（3-4 小时）：
   - 搜索关键词：`Go 语言之旅`（官方中文互动教程：[tour.go-zh.org](https://tour.go-zh.org/)）
   - 重点：变量声明、函数、结构体、接口、goroutine
3. **跟着 Gin 官方文档做 Hello World**：[gin-gonic.com/zh-cn/docs/quickstart](https://gin-gonic.com/zh-cn/docs/quickstart/)
4. **跟学视频教程**（推荐）：
   - [Gin 教程入门实战（B站）](https://www.bilibili.com/video/BV1fA411F7aM/)

**Day 4-7：做一个小项目**

推荐项目：**URL 短链接服务**（适合写简历）

功能需求：
- 输入长 URL → 生成短链接
- 访问短链接 → 302 重定向到原 URL
- 统计每个短链接的访问次数
- 支持自定义短链接

技术栈：`Go + Gin + MySQL + Redis`

具体步骤：
1. 设计数据库表（1 张 `urls` 表：`id, short_code, original_url, visit_count, created_at`）

3. 用 Redis 缓存热门短链接
4. 写 Dockerfile 部署
5. 推到 GitHub，写 README

**Day 8-10：完善 + 写进简历**

- 加上单元测试（Go 自带 `testing` 包）
- 加上 JWT 认证（管理接口）
- 加上 rate limiter 中间件

## P2-2：Linux 基础 + Docker 深入（1 周）

### 学习路径

#### 阶段一：Linux 基础命令（Day 1-3）

**目标：** 能在 Linux 服务器上独立完成日常操作。

**必学命令清单：**

| 分类 | 命令 | 用途 |
|------|------|------|
| 文件操作 | `ls` / `cd` / `cp` / `mv` / `rm` / `mkdir` / `find` | 文件浏览与操作 |
| 文件查看 | `cat` / `less` / `head` / `tail` / `grep` | 查看文件内容 |
| 权限管理 | `chmod` / `chown` / `sudo` | 文件权限控制 |
| 进程管理 | `ps` / `top` / `kill` / `bg` / `fg` / `nohup` | 查看/管理进程 |
| 网络工具 | `curl` / `wget` / `ping` / `netstat` / `ss` | 网络调试 |
| 压缩解压 | `tar` / `zip` / `unzip` | 打包与解压 |
| 包管理 | `apt` (Ubuntu) / `yum` (CentOS) | 安装软件 |
| 文本处理 | `awk` / `sed` / `sort` / `uniq` / `wc` | 数据处理管道 |

**具体步骤：**

1. **安装 WSL2**（Windows 用户）：在 PowerShell 中执行 `wsl --install`，重启后安装 Ubuntu
2. **跟着练习**：
   - 搜索关键词：`Linux 命令行练习平台`（推荐 [Linux Journey](https://linuxjourney.com/) 交互式学习）
   - 或使用 [蓝桥云课](https://www.lanqiao.cn/) 的 Linux 实验环境
3. **每日练习**：在 WSL2 中执行日常操作（用命令行代替资源管理器）

#### 阶段二：Docker 深入（Day 4-7）

**目标：** 能独立编写 Dockerfile、使用 Docker Compose 部署多服务应用。

**具体步骤：**

1. **安装 Docker Desktop**：[docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/)
2. **系统学习**：
   - 阅读 [Docker 从入门到实践](https://docker-practice.github.io/zh-cn/)（开源中文书，第 1-6 章）
   - 跟着每章敲命令
3. **实战练习**：
   - 为你的 HIS AI 服务编写/优化 Dockerfile（已有基础版本，加深理解）
   - 用 Docker Compose 一键启动 `FastAPI + MySQL + Redis` 三个容器
   - 编写 `docker-compose.yml`：
     ```yaml
     services:
       ai-service:
         build: ./ai_service
         ports: ["5001:5001"]
         depends_on: [mysql, redis]
       mysql:
         image: mysql:8.0
         environment:
           MYSQL_ROOT_PASSWORD: "123456"
           MYSQL_DATABASE: his_db
         ports: ["3307:3306"]
       redis:
         image: redis:7
         ports: ["6379:6379"]
     ```
4. **面试必知**：
   - Docker 镜像 vs 容器 vs 仓库
   - Dockerfile 常用指令（FROM / RUN / COPY / EXPOSE / CMD / ENTRYPOINT）
   - Docker 网络模式（bridge / host / none）
   - Volume 数据持久化
