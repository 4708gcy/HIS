  编写 Python 迁移脚本完成 CSV 历史数据的清洗与导入，踩过数据丢失的坑并修复

  \texttt{displayChainByFilter<T>} 泛型筛选消除链表遍历重复代码

\item \textbf{安全机制：}
  SHA-256 加盐哈希（10,000 次迭代，兼容旧版 1,000 次）；
  全参数化查询防 SQL 注入；复方药物成分级分词匹配，解决
  "阿莫西林"误匹配"阿莫西林克拉维酸钾"的假阳性问题

\item \textbf{AI 分析服务（Python）：}
  基于 FastAPI + LangChain 搭建，提供 9 个 REST API 端点；
  传统统计（Holt-Winters 预测、Z-score 异常检测）与 LLM 双策略路由；
  RAG 知识库检索（sentence-transformers 嵌入 + FAISS 向量搜索）
\end{itemize}
